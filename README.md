# Emotiv Public Datasets

A curated index of publicly available EEG datasets recorded with Emotiv headsets
(EPOC, EPOC+, EPOC X, EPOC Flex, Insight).

Full details for each dataset — including task description, publication citation,
channel count, other modalities, and license — are in [`emotiv-datasets.csv`](emotiv-datasets.csv).

## Contributing

Found a dataset that's missing? Open a PR adding a row to `datasets.csv`,
or open an issue with the dataset link.

## Disclaimer

Entries are compiled from public sources. Some fields (license, country,
publication) are marked "Unknown" or "verify" where no clear source was found —
please open an issue/PR if you can confirm one.
